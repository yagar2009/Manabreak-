# Автопоиск вакансий

Рутина Claude «Поиск вакансий» 3 раза в день (≈ 8:46, 13:46, 18:46 по Киеву) запускает новую
сессию на лёгкой модели Haiku. Итог каждого запуска (дайджест вакансий) приходит уведомлением
Claude на почту и push на телефон.

Что ищем: администрирование и создание сайтов (WordPress, WooCommerce, Tilda, Webflow, Shopify),
контент-менеджмент, домены/хостинг, no-code и автоматизация (n8n, Make, Zapier).
Удалёнка из Украины или работа в Украине; штат, part-time и фриланс.

## Как устроено
1. `fetch_jobs.py` — без модели, только стандартная библиотека Python. Забирает фиды DOU и Djinni
   и API Himalayas, отбирает по ключевым словам в названии, оставляет опубликованные за последние
   15 ч (утренний запуск) или 6 ч (дневной и вечерний).
2. Модель делает 3 веб-поиска по work.ua, robota.ua, Jooble и международным удалёнкам
   и отбирает подходящее.
3. Финальный ответ сессии — это дайджест; его доставляют уведомления рутины (email + push).
   Если к рутине подключить Gmail-коннектор (claude.ai → Routines → «Поиск вакансий»),
   она дополнительно отправит HTML-письмо на verzinigor@gmail.com и будет убирать повторы
   по прошлым письмам.

Проверить скрипт вручную:

```bash
python3 -I job-search/fetch_jobs.py --hours 72
```

## Как поменять
- **Ключевые слова / источники** — списки `DOU_SEARCHES`, `HIMALAYAS_SEARCHES`, регулярки
  `INCLUDE` / `EXCLUDE` в `fetch_jobs.py`. Промпт рутины содержит копию скрипта, поэтому после
  правки попросите Claude обновить промпт рутины.
- **Расписание, модель, вкл/выкл** — claude.ai → Routines → «Поиск вакансий», или попросите Claude.
